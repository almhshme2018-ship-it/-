# حروفنا — نسخة البناء السحابي 1.0.0

هذا المشروع مصمم ليُبنى من الهاتف عبر GitHub Actions، دون الحاجة إلى Android Studio على الهاتف.

## ماذا يحتوي؟
- الحروف الهجائية الـ28
- نطق الحروف والكلمات والجمل عبر محرك النطق في الجهاز
- الحركات والمد
- كلمات وجمل قصيرة
- لعبة تمييز الحرف
- تدريب الكتابة بالإصبع
- اختبار تشخيصي مبسط
- النجوم والتقدم محفوظان محليًا
- واجهة عربية RTL

## إخراج APK من الهاتف
1. أنشئ حسابًا في GitHub من الهاتف.
2. أنشئ مستودعًا جديدًا (Repository)، مثل: `Huroofna`.
3. ارفع جميع ملفات هذا المجلد إلى المستودع، مع الحفاظ على مجلد `.github/workflows`.
4. افتح تبويب **Actions**.
5. اختر **Build Huroofna APK**.
6. اضغط **Run workflow**.
7. بعد انتهاء البناء افتح نتيجة التشغيل، ثم قسم **Artifacts**.
8. نزّل `Huroofna-debug-apk.zip` وفك ضغطه، ثم ثبّت `app-debug.apk` على الهاتف.

> ملاحظة: هذه نسخة Debug للتجربة. لاحقًا يمكن إعداد توقيع Release واسم الحزمة النهائي قبل النشر.
